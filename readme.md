# Dead Code Analyzer

A small **dead code removal tool for C programs** with a simple **web interface**.

It uses **Flex (Lex)** and **Bison (Yacc)** to parse a restricted subset of C, detect **unused variables and uncalled functions**, and then emits a cleaned-up version of the code.  
A Node.js/Express server exposes this analyzer over HTTP and serves a minimal front-end.

---

## Features

- 🧹 **Dead variable elimination**
  - Tracks variable usage and removes:
    - Declarations of variables that are never used
    - Assignments to variables that are never used
- 🧾 **Unused function removal**
  - Keeps only the functions that are **actually called from `main()`**
- 🖥️ **Web interface**
  - Paste your C code in the browser
  - Click **Analyze Code** to see the optimized version
  - Buttons to:
    - Load a sample
    - Clear input
    - Copy optimized code
    - Download optimized code
- ⚙️ **CLI-style analyzer behind the scenes**
  - Analyzer reads C code from **stdin** and prints optimized code to **stdout**
  - Node server just pipes input/output between the browser and the analyzer (`dead.exe`)
